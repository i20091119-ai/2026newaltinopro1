경남수학문화관 · 갤럭시탭 SW체험 · 태블릿 1대 = 알티노 1대

0. 준비 (처음 1회)

  1. 태블릿에 알티노 컨트롤 APK 설치(설정 → 출처를 알 수 없는 앱 허용).
  2. 태블릿 [설정 → 블루투스]에서 이 태블릿이 쓸 알티노를 페어링. (차 바닥 스티커 번호 예: BD77 확인) — 앱 안의 [📶 설정] 버튼으로 바로 이동 가능.
  3. 앱 실행 → 홈에서 ① 자율주행 코딩 / ② 수학 연료 꼬리잡기 선택. (①은 학생 활동지+연필 준비)
🔗 연결: 상단 [🔗] → 목록에서 스티커 번호로 검색·선택. 페어링된 알티노가 1대면 자동 연결. 연결이 끊기면 자동 재연결(3초). 🔋 값이 낮으면(빨강) 배터리 교체.

② 수학 연료 꼬리잡기 (도로 매트)

  1. 학년 선택(초1~중3).
  2. 충전소에서 문제 풀기 → 에너지 +500(≈30초 주행분) · 코인 +1.
  3. 에너지가 있는 동안만 D패드로 운전. 다 쓰면 다시 충전.
  4. 뒤에 다른 차가 붙으면 삐-+잡힘+에너지 감소.
  5. 코인으로 속도업 구매(330 → 360 → 390 → 420 → 450, 5단계).
  6. 산 단계 안에서는 상단 속도 −/+ 로 코인 없이 오르내릴 수 있어요 — “너무 빨라서 못 잡겠어요” 대응.
  7. ↺ 잡힘만 0: 에너지·코인·속도는 그대로 두고 잡힌 횟수만 되돌려요(같은 학생이 한 판 더).
  8. 새 판: 모두 처음으로. 두 버튼 다 “정말 하시겠습니까?” 확인창이 떠요.
🏆 가장 적게 잡힌 사람이 승리 (외부 타이머로 시간 관리).
보정: 후면 임계값 기본 50. 너무 잘 걸리면 낮추고, 안 걸리면 살짝 올려요.

① 자율배송 코딩 (n자 코스·6단계)

  1. ①빛(수학): 밝은 곳·터널 안 🔆조도 두 값 측정 → 터널 기준 계산해 입력. → 터널 감지 기준.
    ÷2 / ÷4 선택: 기본은 ÷2(두 값의 평균). 터널이 아닌데 자꾸 “터널!”로 걸리면 ÷4 로 바꿔 기준을 더 어둡게 잡아요. ÷4 는 평균이 아니므로 화면의 이름도 ‘터널 기준’으로 바뀌고, 활동지의 나눗셈 칸에도 실제 고른 수를 적게 해 주세요.
    ⚠ 이 설정은 태블릿에 저장돼 다음 학생에게도 이어집니다. 기준이 너무 낮아 터널을 못 찾게 되는 조합이면 빨간 경고가 뜹니다.
  2. ②암호: 학년(초3~고1, 8개) 문제 풀어 복구 코드.
  3. ③소리: 반복 횟수 + 계이름 2개(터널 미션).
  4. ④배송지: 표에서 문자(N/E/D/W/S) 확인.
  5. ⑤조립(코딩): 활동지에 쓴 숫자를 블록 5개의 빈칸에 넣고 실행 순서대로 배치(조도→전진→장애물회피→소리→문자) → [조립 확인].
  6. ⑥출발! 자동 벽추종 주행 → 터널 소리 🎵 → 도착 문자 표시.
보정: ⑥실행의 [🔧벽추종 보정]에서 TOF 임계·속도·조향을 트랙에 맞게. 상단 TOF 실시간 값 참고.

심화 · 정밀 주차 챌린지

홈 화면 아래 🅿️ 정밀 주차 챌린지 — 먼저 끝낸 친구를 위한 5분짜리 도전입니다.

  1. D패드로 직접 운전해 주차 칸에 차를 세워요(주행 속도는 느리게 고정).
  2. 앞·옆 TOF 거리를 보고 얼마나 정확히 붙였는지 점수로 확인해요.
  3. 연결·짝 해제는 다른 활동과 같은 방식이에요.
대기 줄이 길 때는 생략해도 됩니다 — 본 활동 두 가지와 독립이에요.

앱 업데이트 (지우고 다시 깔 필요 없음)

• 홈 화면 오른쪽 아래 [🔄 업데이트 확인] → 새 버전이 있으면 받아서 그대로 덮어써요. 태블릿 자료는 지워지지 않습니다.
• 처음 한 번은 안드로이드가 “이 앱의 설치를 허용” 스위치를 켜라고 해요. 앱이 그 화면으로 안내하니, 켜고 뒤로 눌러 돌아와 다시 누르면 돼요.
• 태블릿이 와이파이에 연결돼 있어야 해요(유선/학교 망은 GitHub 이 막혀 있을 수 있어요).
• 홈 화면 왼쪽 아래 v1.0.xx 가 지금 설치된 버전 — 12대가 같은 번호인지 눈으로 확인하세요.

문제 해결 (자주 묻는 것)

• 목록에 알티노가 안 떠요 → [📶 설정]에서 먼저 페어링 → 앱으로 돌아와 [🔄 새로고침].
• 차가 안 움직여요 → 상단 🔗 연결됨 확인, 🔋 배터리 확인, (게임)에너지가 0인지 확인.
• 엉뚱한 차가 움직여요 → 🔗 → 이 태블릿의 스티커 번호로 다시 선택.
• 벽에 부딪혀요(코딩) → 벽 감지 거리를 키우고 속도를 낮춰요.
• 소리가 안 나요(코딩) → 차량 부저 음량/음계 코드 확인(강사 문의).
• 다음 학생 → 게임은 [새 판], 코딩은 [← 홈]에서 다시 시작.
• 같은 학생이 난이도만 바꿀 때 → 게임 안 [학년 바꾸기]. 그때만 코인·속도·잡힘이 이어져요(1분 안에 고르면).
• 터널을 못 찾고 계속 달려요(코딩) → ①에서 ÷4 로 기준이 너무 낮아졌는지 확인. 빨간 경고가 떠 있으면 ÷2 로 되돌리세요.
• 도트매트릭스 숫자가 이상해요 → 게임 뷰어의 [🔢 도트매트릭스 방향 맞추기]. 현장 확정값은 7번이에요.

안전

바퀴가 뜬 상태에서 낮은 속도로 먼저 방향 확인 → 정상이면 매트/트랙에 올려요. 주행 중 화면을 벗어나거나 앱을 가리면 자동 정지합니다.
