# 학생 활동지 — 파일 세 가지

| 파일 | 무엇에 쓰나 |
|---|---|
| `학생_활동지.pptx` | **고칠 때.** 파워포인트로 열어 글자·표를 바로 수정 |
| `학생_활동지.pdf`  | **인쇄할 때.** A4 세로 1장, 있는 그대로 출력 |
| `학생_활동지.html` | 웹 원본(PDF 를 만드는 소스) |

## PPT 로 고치는 법
파워포인트에서 `docs/학생_활동지.pptx` 를 열면 된다. **A4 세로 1장**이다.

- **글자**: 그냥 클릭해서 고치면 된다. 모두 진짜 텍스트다(그림 아님).
- **빈칸**: `______` 은 '밑줄 친 빈칸'이라서, 그 자리를 클릭해 바로 타이핑할 수 있다.
  빈칸을 늘리려면 밑줄 친 상태로 스페이스를 더 넣고, 줄이려면 지우면 된다.
- **표**(계이름 8칸, 배송지 표): 진짜 표라서 칸 추가·삭제·색 변경이 다 된다.
- **네모 칸**(정답 쓰는 상자): 도형이라 크기·색을 바꿀 수 있고, 안에 글자도 넣을 수 있다.
- **인쇄**: [파일 → 인쇄] 에서 **전체 페이지 슬라이드**, 용지 A4 세로.

글꼴은 **맑은 고딕**을 쓴다(한국 윈도우 기본). 다른 글꼴로 바꾸면 줄이 밀릴 수 있으니
바꿀 때는 한 장에 들어가는지 확인할 것.

## 내용을 아예 새로 뽑고 싶을 때
`tools/make_worksheet_pptx.py` 가 이 PPT 를 만든다.

```sh
pip install python-pptx
python3 tools/make_worksheet_pptx.py     # → docs/학생_활동지.pptx
```

문항·문구를 바꾸려면 이 스크립트를 고치면 된다. PDF 쪽은 `학생_활동지.html` 이 원본이라,
**둘 다 바꿔야 같은 내용이 된다**(현재 두 파일의 핵심 문구가 같은지 확인해 두었다).
