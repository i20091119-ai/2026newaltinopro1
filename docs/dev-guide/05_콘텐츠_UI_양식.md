# 05. 콘텐츠·UI 양식 가이드

15개 앱이 "한 회사가 만든 앱"처럼 보이게 하는 규칙입니다. 템플릿을 복사하면 대부분 자동으로 지켜집니다.

## 1. 화면 규격

- 기준 해상도 **1280×800 가로 고정**. `body{overflow:hidden}` — 페이지 스크롤 금지, 넘치면 카드 내부 스크롤.
- 색·폰트는 템플릿의 CSS 변수 그대로: 크림 배경, Esamanru 폰트,
  `--mint`(성공) `--coral`(경고/뒤로) `--sun`(보조) `--blue`(기본) `--grape`(특수).
- 터치 버튼 최소 44×44px. `bindHold()`(터치+마우스 겸용)로 '누르는 동안' 버튼 구현.
- 상단바 구성 고정: `← 홈 | 앱 제목 | 센서 칩들 | 연결 상태칩`. 상태칩 탭 = 연결창.
- 짧은 피드백은 `toast()`, 화면 전환은 `.hidden` 토글.

## 2. 문제은행 양식 (수학 문제를 내는 앱)

```js
// 학년 키: e1~e6(초1~6), m1~m3(중1~3) — 필요한 학년만 제공해도 됨
const PROBLEMS = {
  e3: { label: '초3 · 곱셈·나눗셈', list: [ { q: '12 × 3 = ?', a: 36 }, ... ] },
};
```

규칙 (전부 실제 사고에서 나온 것):
- **답은 0 이상의 정수만.** 음수(키패드에 − 없음)·분수·소수 금지. 지문에는 음수 써도 됨.
- 입력창은 `<input type="number" inputmode="numeric">` + Enter 제출.
- 학년당 20문항 이상, 해당 학년 **1학기 교육과정 범위** 준수 (필요하면 교육과정 웹 검증).
- 지수는 유니코드 위첨자(2⁶), 조사(와/과)는 숫자 읽기에 맞출 것 — 기존 `problems.js` 참고.
- 난이도 철학: **체험 활동에서 좌절 금지.** 암산~한 줄 필산 수준. 어렵게 내지 말 것.
- 제출 전 검산: 답을 코드로 재계산하는 검증 스크립트를 돌릴 것 (`scratchpad/gen_problems.mjs` 방식 참고).

## 3. 진행 상태 저장 (필수)

- 키: `altinoT<번호>V1`. 다른 앱 키를 읽거나 쓰지 말 것.
- 저장 시점: 점수/진행이 바뀔 때마다 + (주행 중이면) 2초 주기 + `blur`/`visibilitychange`.
- 재시작 시 자동 복원, **"새로 시작" 버튼이 저장을 삭제** (다음 학생 배려).
- 보정값(임계값 슬라이더 등)도 별도 키로 저장·복원 — 태블릿마다 다시 맞추지 않게.

## 4. 진행 흐름 표준

- 단계형 활동은 상단 스텝바(①②③…)로 현재 위치 표시, `이전`/`다음` 버튼은 좌하/우하 고정.
- 주행 시작 전 `GO!` 연출(1초 정지 → 오버레이 1초 → 출발) — 급출발 놀람 방지.
- 활동 완료 시 명확한 보상 화면(별점/트로피/도트매트릭스 표시 등). 로봇 부저로 성공음(높은도 49) 추천.
- (선택) 관리자 뒷문: 화면 왼쪽 아래 모서리 세로 띠를 1.5초 내 5탭 → 해당 앱의 시연 화면 직행.
  넣는다면 이 위치·제스처 그대로 통일.

## 5. 문구 톤

- 존댓말 해요체, 짧게. 이모지 1개로 포인트 (🚗🎵🔢💡 등).
- 실패 메시지는 격려형: "다시 계산! (큰 수에서 작은 수를 빼요)" — 정답 유도 힌트 포함.
- 연결 안내 문구는 통신 규약서의 표준 문구 그대로 (특히 "페어링 필요 없어요", "Bluetooth No. (예: BF16)").

## 6. 소리·도트·LED 활용 아이디어 (검증된 것)

- 부저 8음계로 짧은 멜로디 미션 (음당 500ms) / 정답 시 '높은도' 삑.
- 도트매트릭스에 점수·횟수·글자 표시 — 반대편 관람객도 보임 (`drawNumber()` 사용).
- LED(15/0)는 이벤트 강조용 점멸 (400ms 켰다 끄기).
- 태블릿 스피커 미리듣기(`beep()`)를 함께 제공하면 미연결 상태에서도 수업 진행 가능.
