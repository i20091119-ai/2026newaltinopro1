# 06. 개발·검증·통합 매뉴얼

## 1. 개발 환경 — 로봇 없이 개발 가능합니다

```bash
# 저장소 루트에서 정적 서버 실행 (아무 정적 서버나 OK)
cd webapp && python3 -m http.server 8099
# 브라우저에서 http://localhost:8099/template.html
```

- 브라우저에는 `window.AltinoNative`가 없으므로 자동으로 **목(Mock) 모드**로 연결됩니다.
  가짜 센서값이 10Hz로 들어오고, 전송 프레임은 `window.__ALTINO_LOG_TX = true` 설정 시 콘솔에 hex로 출력.
- 로직의 90%는 브라우저에서 완성하고, 실기 확인은 APK로.

## 2. 새 앱 만들기 (5분 절차)

1. `webapp/template.html` → `webapp/tXX.html` 복사, `js/template.js` → `webapp/js/tXX.js` 복사.
2. `tXX.html`에서: `<title>`, 앱 제목, 스크립트 태그를 `js/tXX.js`로.
3. `tXX.js`에서: `SAVE_KEY`를 `'altinoTXXV1'`로 변경. ✎ 구역을 자기 활동으로 교체.
4. ★ 공통 구역(연결·스캔·스트리밍·onSensor 골격)은 그대로 둔다.
5. 브라우저(목 모드)에서 흐름 완성 → 검증(아래) → 커밋.

## 3. 제출 전 자가 검증 체크리스트

- [ ] `node --check js/tXX.js` 문법 통과
- [ ] 브라우저 콘솔 에러 0 (로드~주요 흐름 1회)
- [ ] 1280×800에서 페이지 오버플로 없음 (`document.body.scrollWidth <= 1280`)
- [ ] 문제은행이 있다면: 답 전수 재계산 검증 0오류, 음수/소수 답 0개
- [ ] 연결창: 스캔 목록·짝 잠금·`🔓 짝 해제` 동작 (실기 또는 코드 리뷰로)
- [ ] 활동 종료·화면 이탈 시 로봇 정지(`stopAll`) 확인
- [ ] 진행 상태 저장/복원: 새로고침 후 이어지고, "새로 시작"이 초기화
- [ ] (실기) 다른 앱에서 연결 → 내 앱 진입 시 연결 이어받기 확인

Playwright 자동검증 예시는 기존 `full_verify.mjs`(세션 스크래치) 구조 참고:
페이지 로드 → 콘솔 에러 수집 → 버튼 클릭 시나리오 → 오버플로 검사. 앱마다 최소
"로드 무에러 + 핵심 흐름 1개 + 오버플로 없음" 3개는 자동화 권장.

## 4. Git 규칙

- 브랜치: 저자별 `dev/<이름>` 에서 작업 → PR로 `main`(또는 통합 브랜치) 머지.
- **공유층(`protocol.js`/`transport.js`/`android/`) 수정은 단독 금지** — 3인 합의 후 1명이 수정,
  PR에 "공유층 변경" 명시, 전 앱 회귀 확인.
- 커밋 메시지: 한국어로 "무엇을·왜" (이 저장소 로그 참고). 앱 번호 접두 권장: `t07: 문제은행 추가`.
- 충돌 최소화 원칙: 자기 앱 파일(tXX.*)만 만지면 충돌 자체가 없음. `home.html` 등록은 머지 담당 1명이 일괄.

## 5. APK 빌드·배포

- `main`에 푸시하면 GitHub Actions(`.github/workflows/android.yml`)가 자동으로 `app-debug.apk` 빌드.
- Actions 페이지 → 해당 커밋 run → Artifacts → `app-debug.apk` 다운로드 → 태블릿 설치.
- webapp/ 파일은 APK의 assets로 통째로 들어감 — JS만 고쳐도 APK 재빌드 필요.
- 참고: 기관망(유선)에서 GitHub이 차단될 수 있음 — 다운로드는 와이파이/핫스팟으로.

## 6. 통합(머지) 순서 (마지막 주 권장 절차)

1. 각자 자가 검증 통과한 앱 5개를 PR.
2. 머지 담당: `home.html`에 15개 카드 등록 (3열 그리드, 앱 번호 순).
3. 전체 회귀: 15개 앱 로드 무에러 + 임의 3개 앱 실기 연결 테스트.
4. localStorage 키 충돌 전수 확인 (`grep -rn "altinoT" webapp/js/`— 중복 키 없어야 함).
5. APK 빌드 → 태블릿 2대에 설치 → 앱 간 이동하며 연결 승계 확인 → 배포.

## 7. 자주 묻는 질문

- **Q. 연결 코드를 좀 고치고 싶은데요** → 먼저 `02_통신_규약.md`와 사례집을 읽고, 그래도 필요하면 3인 회의로.
- **Q. 스트리밍을 20Hz로 올리면 반응이 빨라지지 않나요?** → 12대 동시에서 끊김이 늘어납니다. 10Hz 고정.
- **Q. 내 앱만 쓰는 공용 함수가 생겼어요** → 자기 tXX.js 안에 두세요. 2개 이상 앱이 쓰게 되면 그때 합의해서 공유층으로.
