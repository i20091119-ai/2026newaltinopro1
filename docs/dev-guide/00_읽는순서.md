# 알티노 학교자율시간 앱 공동개발 가이드 — 읽는 순서

15개 주제 × 전용 앱을 3인이 나눠 개발해 하나의 APK로 합치는 프로젝트의
공통 가이드입니다. 지금까지 부스 현장(경남수학문화관, 태블릿 12대 + 알티노 NEO 12대)에서
실전 검증을 거친 코드와 시행착오를 바탕으로 작성했습니다.

## 3줄 요약

1. **`template.html`+`template.js`를 복사**해서 시작한다. 공통(★) 구역은 안 건드린다.
2. 로봇 제어는 `state.*()` 호출 + 10Hz 스트리밍뿐이다. 하드웨어 수치는 실측표를 믿는다.
3. 학생 진행 상태는 localStorage에 저장하고, 검증 통과 후 제출한다.
