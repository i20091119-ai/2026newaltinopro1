# 알티노 로봇 학교 — 공동개발 가이드 (읽는 순서)

학교자율시간 32차시 프로그램 *알티노 로봇 학교*의 주제 앱 15개를 **세 명이 다섯 개씩 따로 만들고,
통합 담당자 한 명이 합치는** 작업의 공통 가이드다. 2026년 8~9월 경남수학문화관 체험관
(태블릿 12대 + 알티노 NEO 12대)에서 실제로 돌리며 고친 코드와 시행착오를 바탕으로 썼다.

## 통합 담당자

`01_아키텍처_개요.md`(공용 파일·변경 절차) → `06_…` §5~7(합치기·배포·kit 을 고칠 때).

## 다섯 줄 요약

1. **`t00` 을 `tNN` 으로 복사**해서 시작한다. 자기 앱 파일(`tNN.*`, `docs/topics/tNN*`, `tests/tNN.mjs`)만 만든다.
2. 로봇은 **`kit` 으로만** 움직인다 — 패드 `kit.hold`, 자율 동작 `kit.run`, 소리 `kit.beep`·`kit.signal`, 저장 `kit.store`.
3. 값은 **03 실측표**에서 가져온다. 표에 없는 하드웨어(LED 비트 등)는 쓰기 전에 잰다.
4. **현장 조건은 가정하지 않는다** — 코스 모양, 센서 유무, 기기 지원 여부는 확인한 뒤 쓴다.
5. 제출 전 `node tools/check_contribution.mjs tNN` 이 **통과**해야 한다.
