# 03. 알티노 NEO 하드웨어 실측 데이터

체험관 현장(2026-08~09, 12대)에서 재고 검증한 값이다. **각자 다시 실험하지 말고 이 표를 쓴다.**
표에 **없는** 하드웨어를 쓰려면 먼저 재고(§6 절차 참고), 잰 값을 이 문서에 보탠다.
주제 앱은 `kit` 으로만 제어한다(13 문서) — 아래 `state.*` 는 kit 안에서 쓰이는 이름이다.

## 1. 모터 · 조향 — `kit.drive(speed, steer)`

| 값 | 범위 | 실측 감각 |
|---|---|---|
| speed | −1000 ~ 1000 | **300 = 자율 주행 순항**, 330~450 = 꼬리잡기 속도 단계(+30씩), 후진 −300~−350 |
| steer | −127(좌) ~ 127(우) | ±100 일반 회전, ±127 제자리급 회전 |

- ⚠ **250 이하는 제자리에서 출발을 못 한다**(정밀주차 파일럿, 모터가 정지 마찰을 못 이김).
  kit 은 330 미만으로 출발할 때 **첫 180ms 만 400** 으로 밀어 준다(12 S4). 끄려면 `kick:false`.
- 꼬리잡기 최고 속도는 현장 요청으로 450 (처음엔 550 까지 있었다).
- 회전은 바퀴 속도 차가 아니라 **steer** 로 한다(앞바퀴 조향).

## 2. 거리 센서(TOF) — ⚠ 값이 **작을수록 가깝다**

| 필드 | 위치 | 주 용도 |
|---|---|---|
| `ir1` | 전면 좌 대각 | 코너 판단 |
| `ir2` | 전면 중앙 | 정면 벽·긴급 제동 |
| `ir3` | 전면 우 대각 | 코너 판단 |
| `ir4` | 우측면 | 벽 따라가기 |
| `ir5` | 좌측면 | 벽 따라가기 |
| `ir6` | 후면 | 꼬리잡기 '잡힘' |

| 상황 | 값 |
|---|---|
| 앞이 텅 빔 | ≈ 1300 |
| 5cm 앞 | ≈ 60 |
| 쓸 만한 한계 | ~900 (이보다 크면 '벽 없음') |

**검증된 값**

| 용도 | 값 | 출처 |
|---|---|---|
| 정면 벽 감지(ir2) | **220** | 2026-09-20 파일럿, 강사들이 12대로 맞춘 값 (예전 160 은 코너에서 '뱅글뱅글') |
| 좌 대각(ir1) / 우 대각(ir3) | **650 / 210** | 〃 |
| 정면 회피 회전 세기 | **57** | 〃 (127=최대면 제자리를 돈다) |
| '코앞'(후진 필요) | 정면값 × 0.55 | 자율주행 |
| 대각 끼임 | 70 미만 | 자율주행 |
| 측면 긁힘 직전 | 75 (강 90) | 자율주행 |
| 후면 '잡혔다'(ir6) | **50 미만**, 다시 세려면 1.2초 | 꼬리잡기 (120 은 오검출 심함) |
| 주차·컬링 목표 거리 | 90 ~ 200 | 정밀주차 (70 미만은 충돌 위험) |

- **고장 모습**: 센서가 죽으면 값이 **한 숫자에 붙박이**가 된다. 8초 넘게 안 변하면 고장으로 본다(04 #36).
- 위 보정값은 자율주행 앱이 **태블릿에** 저장한다. 앱을 지우고 새로 깔면 날아간다(04 #25).

## 3. 조도 센서 (`cds`)

- 밝은 실내 ≈ 400~800, 손·터널로 가리면 뚝 떨어진다. 화면 표시는 최소 30(0 이 뜨면 고장으로 오해).
- **절대값 기준 금지** — 조명·자리마다 다르다. 반드시 *현장에서 밝은 곳·어두운 곳을 재서 → 사이값* 방식.
- ⚠ **자리마다 다르다**: 창가 자리는 빛이 세서 두 값이 붙는다. **두 값 차이가 120 미만이면 기준을 만들 수 없다** —
  터널 안쪽 깊숙이 넣고 다시 잰다(파일럿, 04 #38).
- 사이값 = (밝음 + 어두움) ÷ 2 = **평균**. 센서가 예민한 자리용으로 ÷4 를 쓸 수 있지만 **그건 평균이 아니다**(04 #32).
- 측정값은 나누는 수의 배수로 반올림해 두면 사이값이 항상 정수 — 초등 계산 배려.

## 4. 부저 — `kit.beep(code, ms)` · `kit.signal(name)`

| 코드 | 37 | 39 | 41 | 42 | 44 | 46 | 48 | 49 |
|---|---|---|---|---|---|---|---|---|
| 계이름 | 도 | 레 | 미 | 파 | 솔 | 라 | 시 | 높은도 |
| Hz(참고) | 523 | 587 | 659 | 698 | 784 | 880 | 988 | 1047 |

- **이 8개만 음정이 확인됐다**(C5~C6, 반음·낮은음 없음). 다른 코드는 쓰지 않는다 — 검사기가 경고.
- 켠 소리는 반드시 꺼야 한다(로봇은 마지막 상태를 유지). `kit.beep` 는 자동으로 끈다.
- 멜로디는 음당 400~500ms 가 또렷하다. **뜻이 있는 소리**(성공·실패)는 신호 사전으로(05 §3).

## 5. 도트매트릭스 8×8 — `kit.dot.*`

- 반드시 kit(→ 공용 `js/dotmatrix.js`)으로 그린다. `state.dotOn` 을 직접 쓰지 않는다.
- 이유(두 번 헛짚고 현장에서 확정): `dotOn(col, row)` 의 `row` 가 **아래에서 위로 세는 번호**다.
  세로축만 뒤집혀 있어서, 모르고 찍으면 상하가 뒤집히고, 거기에 회전을 얹어 "고치면" 좌우 거울상이 된다(04 #10).
- 그림은 **논리좌표**(왼→오, 위→아래)로: `kit.dot.bytes([8바이트])` — 바이트=행(위→아래), 비트7=맨 왼쪽.
- 숫자 `kit.dot.number(0~99)`, 아이콘 `kit.dot.icon('ok'|'no'|'ask'|'heart'|'smile')`.
- 기본 방향 = 현장 확정값(보정 화면 '7번'). 다른 기기에서 이상하면 `kit.dot.calibrate()` — 모든 앱 공용 저장.

## 6. LED — `kit.led(mask)` (0~65535)

- **확인된 것은 두 값뿐**: `15` = 전방등 계열 켬, `0` = 끔.
- 방향지시등·브레이크등이 **어느 비트인지 아직 아무도 재지 않았다.** t05(비밀 신호)·t15(공연 라이트)는
  아래 절차로 먼저 잰다.

**실측 절차 (30분, 로봇 1대)**
1. 견본 앱(t00)을 띄우고 연결한다.
2. 비트를 하나씩: `1, 2, 4, 8, 16, 32, … 32768` 을 차례로 `kit.led(값)` (브라우저 콘솔: `__altinoKit.led(값)`).
3. 값마다 **어느 등이 켜지는지** 사진과 함께 표로 적는다(좌/우, 앞/뒤, 색).
4. 두 대 이상에서 같은지 확인한다(펌웨어 차이 대비).
5. 결과를 이 절에 표로 보탠다 → 그 뒤에 t05 를 만든다.

## 7. 배터리 (`battery`)

- 정상 ≈ 760~800. **700 미만이면 낮음** — kit 상단 칩이 빨갛게 변한다.
- 배터리가 낮으면 로봇이 먼저 연결을 끊는다 — "자꾸 끊겨요"의 1순위 원인.

## 8. 물리 특성

- 로봇은 **마지막으로 받은 프레임을 계속 실행한다.** 멈춤은 우리가 보내야 생긴다(12 문서 전체의 근거).
- 방향 결정을 매 프레임 새로 하면 좌우로 떤다(와리가리) — 한 번 정한 방향은 조건이 풀릴 때까지 유지(04 #7).

## 9. 프레임 바이트 (통합 담당자·시험 도구용)

**송신 26바이트** (`buildFrame`): `[0]=0x02` · `[1]=0x14` · `[2]=체크섬(3~24 합)` · `[5]=steer` ·
`[6~7]=motorA` · `[8~9]=motorB` · `[10]=0xFF 면 도트 모드` · `[11~18]=도트 8행` · `[19]=소리` · `[20~21]=LED`

⚠ **음수 모터값은 2의 보수가 아니다** — `0xFFFF − |v|`(1의 보수). 16비트 정수로 읽으면 −300 이 −301 로 보인다.
시험 도구가 실제로 이렇게 잘못 읽었었다(04 #37).

**수신 54바이트** (`parseSensorFrame`): `[0]=0x02` `[1]=0x30` `[53]=0x03` ·
`ir1~ir6 = [5,7,9,11,13,15]` (각 2바이트, 큰 쪽 먼저) · **`cds = [47]`** · **`battery = [49]`**

## 10. 로봇에 **없는** 것 — 주제 설계 전에 확인

| 바닥을 보는 센서(선 감지) | 정지선·검은 선 따라가기 불가 → 사람이 판정하거나 벽·거리로 대신 | t02 |
