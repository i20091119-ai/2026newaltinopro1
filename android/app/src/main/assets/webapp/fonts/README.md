# 폰트 넣는 곳 — 이사만루체

앱은 `Isamanru` 폰트를 이 폴더에서 찾습니다. 아래 이름으로 파일을 넣어주세요:

- `fonts/isamanru.woff2`  (권장)
- `fonts/isamanru.ttf`    (woff2 없을 때 대체)

## 구하는 법
"이사만루체"는 무료 폰트지만 구글 폰트에는 없어, 이 작업 환경에서는 자동
다운로드가 안 됩니다. 배포처(눈누 noonnu.cc 등)에서 내려받아 위 이름으로
바꿔 넣어주세요. (ttf만 있으면 그대로 `isamanru.ttf`로 넣어도 됩니다.)

폰트가 없어도 앱은 둥근 시스템 폰트로 정상 동작합니다(대체 폰트).
